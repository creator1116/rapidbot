# Code of Conduct

rapidbot is a Minecraft client framework. Its availability does not grant
permission to connect automated clients to any server.

## Use of the framework

- Use rapidbot only on servers where automated clients are explicitly
  permitted by the server owner or operator. When the rules are unclear, ask
  before connecting.
- Follow the server's rules, rate limits, and instructions. Stop using the
  framework on a server if its operator asks you to stop.
- Do not use rapidbot to evade bans, access controls, rate limits, or other
  server rules, or to conceal prohibited automation.
- Run live tests only on servers you operate or have explicit permission to
  test.

## Project community

Treat contributors and users with respect. Keep discussions focused on the
project, provide useful technical context when reporting issues, and do not
request help violating a server's rules or bypassing its enforcement.

Project maintainers may remove content or restrict participation that
promotes unauthorized use of the framework.
